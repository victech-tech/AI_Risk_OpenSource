# Security

## Reporting a problem

Please report security problems **privately** using [GitHub's private vulnerability reporting](https://github.com/victech-tech/AI_Risk_OpenSource/security/advisories/new). Do not open a public issue.

We aim to reply within 5 working days. Helpful details: scanner version, Windows version, and what you found. Never send a real report file that contains personal details.

## What counts

For example:

- The scanner copies a secret (API key, token, password) or personal file content into the report.
- The scanner makes any network connection.
- The scanner changes anything on the computer.
- A released file does not match its checksum or attestation.

## Supported versions

Only the latest release is supported.
